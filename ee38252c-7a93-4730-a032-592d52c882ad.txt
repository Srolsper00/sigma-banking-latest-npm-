## 🚀 Quick Start

### Prerequisites

- Node.js 18+
- pnpm package manager
- Environment variables configured

### Installation

```bash
# Install dependencies
pnpm install

# Start development server
# Note: The Vite dev server is already running in this environment
# Access via the preview surface (do NOT use localhost URLs)
```

### Security Configuration

1. **Set Environment Variables**

   ```bash
   export VAULT_ADDR="https://vault.vombanking.com"
   export VAULT_TOKEN="your-vault-token"
   export ENCRYPTION_KEY="your-encryption-key"
   ```

2. **Configure Firewall Rules**
   Edit `src/app/config/security-config.ts` to customize firewall rules.

3. **Enable/Disable Features**
   ```typescript
   export const SECURITY_CONFIG = {
     firewall: { enabled: true },
     certificate: { autoRenewal: true },
     transaction: { requireSignature: true },
   };
   ```

## 💡 Usage Examples

### Validate Transaction

```typescript
import {
  syntaxFirewall,
  EncryptionUtils,
} from "./config/security-config";
import { FundsTransferPayload } from "./types/transaction-types";

async function processTransaction(
  payload: FundsTransferPayload,
) {
  // 1. Firewall validation
  const validation = syntaxFirewall.validate(
    payload.originator_account.account_number_token,
    "originator_account",
  );

  if (!validation.valid) {
    throw new Error("Security violation detected");
  }

  // 2. Hash verification
  const hash = await EncryptionUtils.hashTransaction(payload);
  if (hash !== payload.metadata.hash) {
    throw new Error("Transaction tampering detected");
  }

  // 3. Process securely
  return await executeTransaction(payload);
}
```

### Enroll Certificate

```typescript
import {
  CertificateApplicationStatus,
  CertificateIssuanceResult,
} from "./types/security-enums";
import { SECURITY_CONFIG } from "./config/security-config";

async function enrollACT2Certificate(chipSerial: string) {
  // Validate chip is pre-registered
  if (!(await isChipRegistered(chipSerial))) {
    return {
      status: CertificateApplicationStatus.REJECTED,
      result: CertificateIssuanceResult.UNREGISTERED_CHIP,
    };
  }

  // Issue certificate with FIPS 140-2 L3 storage
  const cert = await issueCertificate({
    serialNumber: chipSerial,
    tlsLevel: SECURITY_CONFIG.certificate.ca.tlsLevel,
    keyStorage: SECURITY_CONFIG.certificate.ca.keyStorage,
  });

  return {
    status: CertificateApplicationStatus.APPROVED,
    result: CertificateIssuanceResult.SUCCESS,
    certificate: cert,
  };
}
```

## 🔐 Security Best Practices

### DO

✅ Always validate inputs with `syntaxFirewall`  
✅ Use type-safe enums for all security parameters  
✅ Verify transaction hashes before processing  
✅ Check idempotency keys to prevent duplicates  
✅ Log all security events to immutable ledger  
✅ Rotate encryption keys every 90 days  
✅ Enable MFA for all admin accounts  
✅ Use tokenized account numbers (never plaintext)

### DON'T

❌ Store plaintext account numbers  
❌ Skip signature verification  
❌ Disable the syntax firewall  
❌ Use weak encryption algorithms  
❌ Log sensitive data (redact first)  
❌ Trust user input without validation  
❌ Bypass RBAC checks  
❌ Ignore certificate expiration warnings
